## Where Is the Specimen?

A new procedure entry inherited a cytology destination. Existing biopsy and
cytology examples were tested, but the newly added excision code was omitted.
The accessioning scan records physical receipt; the queue assignment does not.

Storyboard: timestamped records → distinguish location from assignment → compare
procedure entries with approved destinations → edit individual routes and the
unmatched-code branch → replay affected and neighboring procedures → choose a
documented physical recovery plan. A software correction cannot create a scan.

Acceptance: original configuration fails excision and unknown-code cases;
all-gross-room routing also fails cytology and frozen section; targeted repair
preserves neighboring routes. Physical recovery remains a separate requirement.
Debrief stays available. Test desktop and narrow layouts before publication.
