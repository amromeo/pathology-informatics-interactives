# Model Under Pressure

You are the pathology resident helping Dr. Rao review a machine-learning model that marks possible metastases on digital lymph-node slides. The laboratory is thinking about using those marks to point the pathologist to areas worth a closer look. The pathologist would still examine the whole slide, including unmarked tissue.

### Why Dr. Rao wants a closer look

The vendor reports that the model found metastases on 192 of 200 known-positive slides, or 96%. Those slides were scanned on a scanner the vendor supports.

Your laboratory uses two scanners and a different staining procedure. When staff tested the model on 50 local slides known to contain metastases, it found 42 and missed eight. Dr. Rao wants to understand those misses before the laboratory relies on the model's marks. You will compare results for micrometastases and macrometastases on each scanner, then examine what happened over the next two months.

The committee also has three other proposals in front of it: a rule that holds laboratory results for review, a program that groups tumors by their measurements, and a program that writes a summary. Each does a different job, and you will use them to see why different programs need different checks.

## Terms used in this case

### How the programs work

- **Programmed rule:** a condition and action written by a person. For example, hold patient results when a quality-control result falls outside the allowed range.
- **Artificial intelligence (AI):** a broad term for computer methods that perform tasks such as recognizing images or producing language. **Machine learning** is one approach: developers use examples to adjust a model.
- **Model:** a set of calculations that turns an input into an output. Here, the input is a slide image and the output identifies areas that may contain metastases.
- **Training and parameters:** training adjusts the model using examples. Parameters are the numbers within its calculations that are adjusted. The trained model uses those saved numbers when examining a new slide.
- **Labels and supervised learning:** labels are the answers attached to the training examples. Supervised learning uses those answers during training; this slide model learns from images in which pathologists have marked the cancer.
- **Unsupervised clustering:** grouping examples by similarities in their measurements. For example, a program may group tumors with similar measured gene activity.
- **Generative model:** a model that produces content, such as a written summary of reports. Its output has to be checked against the original reports.

### Comparing the model's calls with the slides

- **Reference standard:** the answers used to judge the model's calls. In this case, pathologists decide which slides contain metastases before the model is tested.
- **True positive and false negative:** a true positive is a slide with metastasis that the model calls positive. A false negative is a slide with metastasis that the model misses.
- **False positive and true negative:** a false positive is a slide without metastasis that the model calls positive. A true negative is a slide without metastasis that it correctly calls negative.
- **Sensitivity:** the fraction of slides with metastases that the model detects. Start with all slides known to contain metastases, then count the ones it found.
- **Specificity:** the fraction of slides without metastases that the model correctly calls negative. Start with all slides known to be negative.
- **Positive predictive value (PPV):** the fraction of the model's positive calls that actually contain metastases. Start with all positive calls, including false alarms.
- **Prevalence:** the fraction of slides in the group that contain metastases. The prevalence slider in this lesson changes that fraction in the example calculation.

### Performance in a new setting and over time

- **Generalizability:** how well performance carries over to new cases or settings, such as this laboratory's scanners and staining procedure.
- **Drift:** a change over time in the model's inputs or performance. The monthly review checks for changes after the first local test.
- **Brittleness:** a large change in the model's answer after a small change in its input, such as a slight color shift in an image.

## What you will be able to do

- Explain the difference between a rule written by a person and a model trained on examples.
- Read the model's test results and say which positive slides it found and which it missed.
- Tell a problem that was there from the first local test apart from a decline that starts later.
- Explain why a positive call may be wrong even when the model detects most metastases.
- Before patient use, choose the record that answers each of four questions: missed lesions, who does which job, model settings and regulatory authorization.
