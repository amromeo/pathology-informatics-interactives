## Debrief: explain what the model found and missed

Begin with two separate answers: what the pathologists found on the slide, and what the model called. The pathologists' agreed diagnoses are the reference standard for this test. A slide containing metastasis is a true positive only if the model finds it. If the model misses it, that outcome is a false negative.

In [Table 1](#ai-local-results), the model found 42 of 50 positive slides and missed eight. Its sensitivity was therefore 42/50, or 84%. [Table 4](#ai-local-summary) sorts those results by deposit size and by scanner, so you can see where the misses were.

### A poorer local result and a later decline

The vendor found 96% of its positive slides, while the first local test found 84%. That difference was present when the model was first brought into this laboratory. It raises a generalizability question: how well does performance carry over to new cases and a new setting?

September asks a different question. In [Table 2](#ai-monthly-results), local detection of small deposits fell from 17/25 to 12/25. The model missed 13 small deposits that month. Staff had changed the staining procedure. That is one possible cause to investigate alongside scanner use, case mix, slide quality and the pathologists' diagnoses.

A change over time is called drift. The laboratory needs regular reviews to detect it. If a result crosses the stopping limit agreed before use, staff should pause use while the team investigates. These monthly counts do not show whether a small change to the same image would produce a large change in the model's answer; that would require a separate test for brittleness.

### Sensitivity and positive predictive value start with different groups

For sensitivity, start with all the slides that contain metastases and count how many the model finds.

For positive predictive value, start with all the slides the model calls positive. Some are correct calls; others are false alarms on slides without metastases. Divide the correct positive calls by the total number of positive calls.

In the [slider results](#ai-calculated-outcomes), reducing prevalence from 10% to 1% changes a group of 10,000 slides from 1,000 containing metastases to only 100. The example model still finds the same proportion of those positive slides when separation stays fixed. But the much larger negative group continues to produce false alarms. Those false alarms make up a larger share of all positive calls, so positive predictive value falls.

The 50 observed positive slides cannot answer that question by themselves. We would also need results from negative slides. The calculator shows the reasoning using assumed performance; it does not supply those missing local observations.

### Different programs make different kinds of mistakes

The written quality-control rule can mishandle a boundary or an exception. Test whether it holds or releases results under those conditions.

The image model can miss metastases on new slides. Compare its marks with diagnoses that pathologists made before running it. Include micrometastases and images from each scanner.

The clustering program can put similar measurements together without identifying a useful disease category. Compare the diagnoses, gene activity and sample-preparation methods within each cluster. A cluster may reflect tumor biology or a difference in how samples were handled.

The generative model can produce a readable summary with an invented finding or an important omission. Compare it with the original reports before using it at tumor board. A generative model could have been trained with supervised examples: “supervised” describes its training, while “generative” describes its output.

### Choose records that answer the question

To compare misses between sites, review local test results separated by site and deposit size. Use the number of known-positive slides at each site as the denominator. A software-version record cannot tell you how many metastases were missed.

To find out who reviews the whole slide, who deals with errors and who can pause use, read the laboratory procedure that assigns those jobs. The laboratory director and the reviewing pathologists should agree on those jobs, and on when to stop, before use.

To investigate a particular result, review its saved model version and scanner, stain and threshold settings. The current settings may differ from those used when the result was produced.

To check whether the proposed use is covered by the product's authorization, review the current authorization and instructions for use with the hospital's regulatory team. Local detection results answer a performance question. The authorization answers which uses and conditions are covered.

Good detection of large deposits in this small test does not automatically approve a narrower use. The team would still need to define that use, test it properly and decide how the pathologist will check the program's output.

<summary>A closer look: keep a reference that the model did not supply</summary>

Pathologists need diagnoses made independently of the model’s marks when they check what it found and missed. If reviewers see the marks first and inspect only those areas, a small unmarked metastasis may never enter the comparison. The apparent result then depends partly on the program being tested.

The first local review should include slides from each scanner and deposits of different sizes. Later reviews also need saved versions, stain settings and the dates when those settings changed. These records help the team investigate a decline without assuming that the most recent change caused it.

Retraining creates another reason to preserve independent review. If staff routinely accept a program’s suggestions, those answers may become labels for its next training set. Keep a way to examine difficult cases and unmarked tissue.
