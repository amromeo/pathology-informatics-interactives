# Faculty guide: Model Under Pressure

## At a glance

Allow 40 minutes. Begin with the four proposals, then spend most of the discussion on what the detector missed locally. The lesson covers PIER 2.4, including model types, local testing, changes over time and review before patient use.

## Run of show

| Minutes | Activity | Ask the group |
| --- | --- | --- |
| 0–10 | Classify the four proposals and choose a first check | Which conditions did a programmer write? Which patterns did a model learn? |
| 10–22 | Compare scanner, lesion-size and monthly counts | Which missed slides would you pull first? |
| 22–30 | Move prevalence and separation | Why did positive predictive value change? |
| 30–40 | Sort the questions about patient use and discuss the checks | Who could stop use if next month's results were worse? |

## Expected answers

**Proposals:** P1 is a programmed rule; test its limits and exceptions. P2 is supervised image detection; test it locally against independent diagnoses. P3 is unsupervised clustering; find out what the groups mean. P4 generates text; compare the summary with its source reports.

**Slide counts:**

- Vendor: 192/200 = 96%.
- Local total: (10 + 13 + 7 + 12)/50 = 84%.
- Micrometastases: (10 + 7)/25 = 68%.
- Macrometastases: 25/25 = 100%.
- Scanner A: 23/25 = 92%; scanner B: 19/25 = 76%.
- September: (12 + 25)/50 = 74%.

The poor local result from the start is a generalizability problem. September adds a later decline that needs investigation. The stain change is a possible explanation to test.

**Questions before patient use:** G1 concerns whether the tool works equally well for the groups of patients served. G2 concerns who reviews its work and can stop use. G3 concerns records of versions and settings. G4 concerns the product's device status and whether it covers the proposed use.

**Sliders:** sensitivity and specificity both equal 1 / (1 + exp(-separation)). Expected true positives are 10,000 × prevalence × sensitivity. Expected false positives are 10,000 × (1 − prevalence) × (1 − specificity). Positive predictive value is true positives / (true positives + false positives). Changing prevalence alone leaves sensitivity fixed.

## Common misconceptions

- **“The vendor found 96%, so we should too.”** Ask: which scanner, stain and slides did the vendor test?
- **“An overall 84% tells us enough.”** Ask: how many of the micrometastases were missed?
- **“Any poor result is drift.”** Ask: was detection ever better in this laboratory?
- **“Finding every macrometastasis means we can use it for those.”** Ask: who has reviewed and approved that narrower task and how the pathologist will use the output?
- **“The summary reads well, so it must be right.”** Ask: where is each finding stated in the source reports?

## Discussion prompts

1. What would Dr. Rao need before trying the detector with pathologists? *A strong answer:* a defined task, independent local diagnoses, results for the relevant slide groups, and a plan for human review and stopping use.
2. Why can positive predictive value fall while sensitivity stays fixed? *A strong answer:* when disease is less common, negative cases make up a larger share of the population. False positives from that group account for more of the model's positive calls.
3. Does September prove that the stain change caused the decline? *A strong answer:* no. Review the case mix, slide quality and reference diagnoses, then compare the changed stain under conditions that help separate those explanations.

## Group variant

Give residents the roles of laboratory director, reviewing pathologist, analyst and treating clinician. Each names one question they need answered before using the tool. Ask a fifth resident to explain what a patient would want to know about a missed lesion.

## Assess transfer

Ask the resident how they would change the local test for a new scanner, then for a generated pathology summary. Look for a change in what they would check, rather than the same checklist with a different title.
