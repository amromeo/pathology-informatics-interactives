# Faculty guide: Model Under Pressure

## At a glance

Allow 40 minutes. PIER 2.4: model types, verification, generalizability, drift, brittleness, implementation and oversight. Use individual prediction followed by small-group discussion. Project the verification and monitoring tables.

## Expected answers

P1 rule/boundaries; P2 supervised/local; P3 unsupervised/meaning; P4 generative/sources. The initial gap is generalizability failure. September requires investigation of a change over time. G1 equity, G2 accountability, G3 documentation, G4 device status.

Vendor detection: 192/200 = 96%. Local: (10+13+7+12)/50 = 84%; micro: (10+7)/25 = 68%; macro: 25/25 = 100%. Scanner A: 23/25 = 92%; B: 19/25 = 76%. September: (12+25)/50 = 74%. These small selected positive sets do not estimate specificity, predictive value or patient outcomes.

The slider model uses sensitivity = specificity = logistic(separation), with a fixed threshold. Expected true positives equal 10,000 × prevalence × sensitivity. False positives equal 10,000 × (1-prevalence) × (1-specificity). Predictive value is TP/(TP+FP). Prevalence alone does not change sensitivity in this model.

## Common misconceptions

- Vendor performance transfers automatically. Ask which scanner, stain and cases were tested.
- A pooled rate is sufficient. Ask which lesions are missed.
- Every performance gap is drift. Ask whether it was present at first use.
- Fluent generated text is reliable. Ask where each statement appears in the source.
- A high macrometastasis rate permits a new use. Ask who approved the scope and workflow.

## Discussion prompts

1. What must happen before a restricted pilot? A strong answer includes intended use, independent local evidence, human review and stop criteria.
2. Why can predictive value fall when sensitivity stays fixed? A strong answer includes the increasing number of negative cases supplying false positives.
3. Does September prove the stain change caused the decline? A strong answer includes case mix, reference review and a controlled investigation.

## Group variant

Assign laboratory director, pathologist, analyst, clinical service and patient advocate. Review the same packet from each role, then agree on an unresolved question and an accountable person.

## Assess transfer

Ask how the verification plan would change for a different scanner or a generated pathology summary.
