# The Pixel Budget

> **Synthetic image lab:** The same specimen image is available as a large TIFF, a lossless copy, and two lossy JPEG variants. The reviewing display is overdue for calibration.

## Your task

Compare crop, resampling, resolution, format, compression, pyramid level, metadata, and display conditions. Choose settings that are fit for a defined clinical or educational use.

## Key point

Image quality is a property of the complete capture–file–viewer–display system. File extension and pixel count alone do not establish diagnostic adequacy.
