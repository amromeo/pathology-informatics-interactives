# Review one local automatic-release rule

## Who to meet

A chemistry supervisor and the analyst who looks after the LIS or middleware rule.

## Time

30–60 minutes.

## Steps

1. Choose an approved rule with the supervisor. Note the order type, assay and patients it applies to.
2. Read the written criteria side by side with the conditions set in the software. Ask the analyst to show how the program combines them.
3. Follow one held and one released result through the checks. Note each input and where it comes from.
4. Look through the validation records for results exactly on a limit, missing history, instrument flags and a result that should still be released. Include a missing-input example if the rule calculates another result.
5. Ask who approves a change, where it is tested, how staff watch how it behaves and how they would switch it off or undo it.

## Bring back

A diagram of the checks and a small table of the expected hold or release decisions. Name the saved rule version and why each example is in the test set.

## Discuss with faculty

Which condition would you test on its own? How would you spot results held for no reason, as well as results released that should have been held?

## Privacy

Use only records your supervisor allows you to review. Keep patient identifiers and screenshots in the hospital's own systems, and bring back a description with no patient identifiers.
