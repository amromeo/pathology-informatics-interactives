# Checking Automatic Result Release

At the morning chemistry review, the supervisor finds a troponin result that was
released automatically even though it met one of the laboratory's approved review
criteria. You are the pathology resident working with the supervisor and the
middleware analyst to explain the release and check a proposed correction.

## What changed

The laboratory moved its troponin release rules from the laboratory information system (LIS) into middleware last
week. Middleware receives instrument results, applies the release checks, and
sends the resulting status to the LIS. The analyst transferred the absolute-change
check, but the review must confirm whether the complete approved policy was
implemented. The initial validation included stable results and large absolute
changes; it did not cover all combinations of the two change criteria.

### Result reviewed at 08:00

| Record | Value |
| --- | --- |
| Accession | AV-01 |
| Current troponin, 07:40 | 48 ng/L, final |
| Prior troponin, 04:40 | 12 ng/L, same assay and patient |
| Quality control | Accepted for this run |
| Instrument flags | None unresolved |
| Middleware action | Automatic release |

The laboratory has an approved policy for reviewing certain changes before release.
The problem is whether the configured rule follows that policy. A rising troponin
is not, by itself, proof that a result should be delayed or that the analyzer is
wrong. The clinical team interprets the result in the patient's clinical context.

## Your task

Calculate the change, compare the configured branches with the approved policy,
and inspect the reason each result is released or held. Correct the rule, then
test results that should still release, boundary values, and exceptions. Explain
what the laboratory director needs before approving production use.


## What you will be able to do

- Test a release rule with both held and releasable results.
- Compare the rule with the approved order pathway.
- Explain why “change the threshold until fewer cases hold” is an incomplete approach.

Start by reading the case records. Make a choice before checking the explanation; you can revise it and test again.
