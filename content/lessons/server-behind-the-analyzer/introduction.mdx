# The Server Behind the Analyzer

> **Synthetic case:** A proposed middleware server will sit near instrument heat vents, use unrestricted local access, store PHI, and permit persistent vendor remote support.

## Your task

Conduct a layered threat review using confidentiality, integrity, and availability. Identify physical, identity, network, vendor, regulatory, contractual, and recovery controls.

## Concept lens

Security controls protect clinical service as well as privacy. A server that routes laboratory results is a patient-care dependency even when it is physically located inside the laboratory.
