# The Server Behind the Analyzer

> **connected case:** North River University Hospital is a Level I trauma center. In March 2026, the hospital plans to install a middleware server that will receive instrument results and route them to the laboratory information system.

## Case setup

Dr. Maya Chen, a pathology informatics fellow, joins Jordan Ellis, a laboratory information system (LIS) analyst, for the pre-installation review requested by Dr. Elena Ruiz, the core laboratory medical director. The review documents a proposed server location beside instrument heat vents, shared local access, protected health information stored on the server, a flat instrument network, a persistent vendor support connection, and a backup that has not been restored in a test environment.

The hospital will proceed with the installation before every recommended control is complete. That later decision is part of the fixed chronology shared by all three Topic 3 cases; your work here is to identify the risks and recommend a defensible plan before installation.

## Your task

Inspect the installation findings and trace who would encounter each risk in ordinary laboratory work. Decide whether the findings can be corrected one at a time or require a coordinated plan, then run the proposed plan against environmental, access, network, vendor, and recovery checks.


## What you will be able to do

- Match a security finding to its laboratory consequence.
- Review the approved access and risk assessment.
- Explain why “count passwords without reviewing access” is an incomplete approach.

Start by reading the case records. Make a choice before checking the explanation; you can revise it and test again.
