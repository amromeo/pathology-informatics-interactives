### Work through one finding

Suppose someone uses the shared unrestricted account to open a patient's queued result and change its destination. Viewing that result without permission threatens **confidentiality**. Changing the routing setting threatens **integrity**. The shared account also prevents Jordan from determining which person acted. In this finding, the described actions concern viewing and changing records; the exercise does not describe a service interruption.

For each remaining finding, identify the record or service, describe what could happen to it, and select the affected properties. Heat or sudden power loss can stop routing (**availability**) and interrupt a write to storage, leaving a queue incomplete or damaged (**integrity**). A backup requires both checks: can staff restart the service, and are the restored orders, results and settings complete and correct?

The map scores the effects described for each finding. Other consequences may be possible; be prepared to explain the additional chain of events rather than selecting every property automatically.

### How the controls change those events

Jordan can replace the shared login with named accounts and limit who can change routing settings. An audit log then connects a recorded change to an account. Vendor work also needs an approved start, an agreed task, a record of changes and an end to the connection.

The network team can allow instrument messages through a restricted boundary while denying unnecessary access to server files. This is network segmentation. A separate network path addresses a different problem: if construction cuts the only cable route, segmentation cannot provide a replacement connection. A backup can recover saved data after loss; it cannot reconnect a cut cable either.

The control builder assigns each option budget and staff-effort points. Add the selected points separately and stay within **15 budget points and 11 staff-effort points**. These are exercise limits for comparing priorities. For example, protected hosting costs 4 budget and 1 effort; named accounts cost 2 and 2. Together they use 6 budget and 3 effort. Inspect what still lacks protection before spending the rest.

In the [five event checks](#stress-test-title), **Blocked** means the selected control stops the particular event as described. **Partially mitigated** means harm is reduced but an interruption or access path remains. **Not mitigated** means none of the selected controls addresses that event. The summary counts both blocked and partial results as covered. Read each explanation before recommending the plan.

### Which review is needed?

HIPAA's Security Rule addresses administrative, physical and technical safeguards for ePHI. For this installation, the hospital's risk analysis should connect the identified problems to access controls, audit records and recovery procedures. The [HHS Security Rule summary](https://www.hhs.gov/hipaa/for-professionals/security/laws-regulations/index.html) explains these obligations and distinguishes the rule in effect from proposed changes.

The vendor will handle PHI while supporting the hospital's server. The hospital must review the business associate arrangement and agreement as well as the technical access. A signed agreement and an approved, limited support session each serve a purpose. The research data use agreement in the later privacy case serves a different disclosure pathway.

If an incident may have exposed patient information, involve the privacy office promptly for breach assessment and any required notification. Restoring the server does not finish that review. Records covered by **42 CFR Part 2**, the federal protections for certain substance use disorder records, and applicable state laws require additional review. A diagnosis alone does not determine whether Part 2 applies; the source program and records matter.

In the later review questions, select the review that answers the stated question. Several obligations can apply to one installation. For example, an access log can support both security work and an accreditation review; the question identifies which review is being requested.
