# Validate Before Go-Live

> **Synthetic case:** Overall whole-slide-image concordance is 96.1%, but frozen sections reach only 82.4%. Two remote displays and several intended workflows were not tested.

## Your task

Navigate representative regions, investigate discordance, and build a validation matrix across specimen categories, scanners, displays, users, sites, and workflows. Decide whether the proposed scope is ready.

## Key point

Validation supports an intended use. Aggregate concordance cannot compensate for a clinically important subgroup failure or an untested component of the deployed system.
