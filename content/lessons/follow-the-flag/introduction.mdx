# Follow the Flag

> **Synthetic case:** Potassium is 6.8 mmol/L. The analyzer and LIS call it critical high, the interface receives it successfully, and the EHR shows a generic blue flag.

## Investigate before repairing

Trace the value and abnormality code through each system. Inspect the HL7 observation fields and decide whether the failure is transport, syntax, terminology, or receiver configuration.

Use the evidence panels to separate successful transport from correct semantic interpretation before changing the mapping.

## Concept lens

An acknowledgment confirms receipt, not correct interpretation. Syntactic interoperability moves fields; semantic interoperability preserves usable meaning.
