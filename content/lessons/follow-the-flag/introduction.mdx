# Tracing a Missing Critical Flag

At 08:10, a chemistry supervisor opens the electronic health record (EHR) laboratory report for accession
FL-01. Potassium is **6.8 mmol/L**, but the report has no critical-high indicator.
The laboratory information system (LIS) shows the same result with its local **CH** flag. The technologist has
already documented the required critical-result call. You are the resident
working with the LIS analyst to investigate the incomplete electronic display.

A new EHR connection went live yesterday. Validation included normal, high, and
low results, but the local critical categories were not represented in the
display checks. The interface engine copies result fields from the LIS into
messages for the EHR. Its current transformation leaves the flag unchanged.

## Your task

Compare the source result, outbound message, receiver log, and clinical report.
Select message fields to learn what they carry. Translate both critical
categories without changing routine categories, then test the unknown-code
branch. Finish by distinguishing a mapping correction from the follow-up needed
for results that were already displayed incompletely.


## What you will be able to do

- Distinguish message receipt from faithful result meaning.
- Compare the source message with the received report.
- Explain why “repeat the transmission without inspecting fields” is an incomplete approach.

Start by reading the case records. Make a choice before checking the explanation; you can revise it and test again.
