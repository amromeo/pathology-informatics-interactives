# Tracing a Missing Critical Flag

At 08:10, a chemistry supervisor opens the laboratory report for accession FL-01 in the electronic health record (EHR). Potassium is **6.8 mmol/L**, but nothing on the report marks it as critically high. In the laboratory information system (LIS), the same result carries the laboratory's own **CH** flag, and the technologist has already recorded the critical-result phone call. You are the resident working with the LIS analyst to find out why the EHR shows less than the LIS.

A new connection to the EHR went live yesterday. Testing covered normal, high and low results, but nobody checked how the laboratory's critical flags looked in the EHR. The interface engine copies result fields from the LIS into messages for the EHR. As it is set up now, it passes the flag through unchanged.

## Your task

Compare four records for the same result: the LIS result, the message sent, the EHR's receipt log and the report clinicians see. Select fields in the message to see what each one carries. Translate both critical flags without changing the routine ones, then test what happens to a flag the EHR does not recognize. Finish by separating the fix to the translation from the follow-up needed for results that already went out without their flag.

## What you will be able to do

- Tell a message that arrived apart from a result whose meaning arrived intact.
- Compare the message the laboratory sent with the report the EHR shows.
- Explain why sending the message again, without looking at its fields, does not fix the problem.
