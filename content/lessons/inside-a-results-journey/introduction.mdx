# Inside a Result’s Journey

> **Synthetic case:** A verified CBC is visible on the analyzer and in the LIS, but not in the EHR.

## Your task

Trace the result through hardware, system software, application software, networks, and communication protocols. Use the evidence at each boundary to localize the fault instead of guessing from the clinical symptom.

## Key point

Hardware executes work. System software manages resources. Application software supports laboratory tasks. Network protocols define how components exchange data. In a clinical system, all four layers contribute to whether a result reaches the correct user.
