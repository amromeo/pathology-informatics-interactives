# The Missing CBC

The emergency department (ED) calls the hematology lab about a patient with a suspected gastrointestinal bleed. The complete blood count (CBC) still says **Pending** in the electronic health record (EHR), and the clinician is waiting for the hemoglobin.

You are the pathology resident working with the hematology technologist and the laboratory information system (LIS) analyst. From the ED, "Pending" looks the same whether the CBC is still being run or it is finished and stuck on its way to the chart.

The LIS is the application the laboratory uses to manage orders, specimens and results. Once a result is released there, it still has to travel to the EHR before the clinician can read it. In this hospital, an **interface engine** takes the message from the LIS and sends it on to the EHR. All three systems run in the health system's own data center and talk to each other over its internal network.

The interface team did scheduled maintenance earlier this morning. You will look at each system's records to find where the result stopped, and whether a setting changed during that work.

## Terms used in this case

### Systems and messages

- **LIS and EHR:** the laboratory information system manages laboratory orders, specimens and results. The electronic health record brings information from every service together in the patient's chart.
- **Interface engine:** software that takes messages from one system, reformats them if needed and sends them on to another. Here, it carries reports from the LIS to the EHR.
- **Queue:** a list of messages waiting to be sent or accepted. A queue that keeps growing tells the analyst that results are piling up somewhere.
- **Health Level Seven (HL7):** standards for exchanging health information. An HL7 laboratory message puts the patient identifier, test, result, units and other items in agreed fields.
- **Acknowledgment (ACK):** a reply from the receiving system saying it accepted the message or found an error. The analyst looks for that reply when tracing a message.

### Computers and connections

- **Hardware:** physical equipment, such as a computer's processor, memory, storage and network adapter.
- **Operating system:** the software that runs the computer itself and lets applications use its memory, storage and network connection.
- **Application:** software that does a particular job. The LIS and the interface engine are applications.
- **Internet Protocol (IP) address:** the address used to reach a computer on the network. In this case, `10.20.30.40` is where messages for the EHR are sent.
- **Port:** a number that sends a connection to one particular service on that computer. In `10.20.30.40:5000`, the number after the colon is the port.
- **TCP/IP:** the set of rules computers use to send data over a network. Internet Protocol gets each piece of data to the right address. Transmission Control Protocol (TCP) checks that everything arrived, resends anything lost and puts the data back in order.
- **Client and server:** the client starts the connection and the server waits for it. Here, the interface engine is the client and the EHR's receiving service is the server. People also call the computer that runs a service a server.

## Your task

First, check whether the laboratory already has a verified CBC. If it does, the ED needs that result now, by phone, while the LIS analyst finds out why the electronic report is missing. Then follow the result through each system, find the connection that failed, and decide what to check once it is fixed.

## What you will be able to do

- Explain the different jobs of a computer, its software and its network connection.
- Use a record from each system to tell how far a result got.
- Check that delayed and new reports reach the right charts once a connection is fixed.
