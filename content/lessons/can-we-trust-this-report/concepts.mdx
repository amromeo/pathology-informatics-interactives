## Follow the accession time into the report

The LIS stores each accession time in its own field, and a spreadsheet formula can use that field to calculate TAT. It cannot read a time handwritten on a scanned requisition.

During cutover, the original accession times for 27 cases were written only on the requisitions and the paper log; their LIS fields were left blank. The coordinator looked up those times and typed them into a separate column of the spreadsheet, so TAT could still be calculated for those cases.

That leaves two separate questions. Does the spreadsheet use the right time, the moment each case was actually accessioned? And is the LIS field still blank? A spreadsheet that calculates correctly does not mean the LIS record has been fixed.

## Name the question each check asks

Each check below asks one kind of question about the data. These kinds of question are often called **data-quality dimensions**. Use the seven below to sort the checks in this case.

- **Accuracy:** does the value match what actually happened? Compare a filled-in accession time with the requisition or log written at the time.
- **Completeness:** is the required information there? Count the blank accession-time fields, even if the coordinator found the times elsewhere.
- **Validity:** is the value in the right format, and does it make sense? Check that each timestamp reads as a date and time, and that no case is signed out before it was accessioned.
- **Consistency:** is the same definition used throughout? Check that every period measures from accessioning to the initial final report.
- **Uniqueness:** is each accession counted once? An amended report should stay with its case, not add another row.
- **Timeliness:** are the data up to date when they are needed? Check that the April 20 export includes cases accessioned by April 3 that were signed out late.
- **Fitness for purpose:** can this analysis answer the laboratory's question? Lumping all post-go-live weeks together hides the difference between cutover and the weeks that followed.

A time can be in the right format and still be wrong. If it records when someone typed the case in later, rather than when it was accessioned, it passes the validity check and fails the accuracy check. A blank field is a completeness problem: there is nothing there yet to judge for accuracy.
