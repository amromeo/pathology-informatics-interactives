## Follow the accession time into the report

The LIS stores each accession time in a defined field. A spreadsheet formula can use that field to calculate TAT. It cannot automatically read a handwritten time in a scanned requisition unless a separate extraction process has been built.

During cutover, 27 original accession times remained on the requisitions and paper log, while their structured LIS fields were blank. The coordinator checked those documents and entered the times in a separate spreadsheet column. The report could then calculate TAT without losing those cases.

This creates two questions. Does the spreadsheet use the correct original event? And is the LIS field complete? A usable spreadsheet does not mean that the underlying LIS record has been repaired.

## Name the question each data check answers

A **data-quality dimension** is a way to describe a particular kind of check. Use the seven terms below to classify the checks in this case.

- **Accuracy:** does a value describe what actually happened? Compare a populated accession-time field with the contemporaneous source record.
- **Completeness:** is the required information present? Count blank accession-time fields, even when a coordinator recovered the times elsewhere.
- **Validity:** does the value follow the required format and rules? Check that a timestamp can be read as a date and time and that finalization does not precede accession.
- **Consistency:** is the same definition used throughout? Confirm that all periods measure accession to the initial final report.
- **Uniqueness:** is each accession counted once? An amendment should remain attached to its case rather than create another case row.
- **Timeliness:** are the data available and current when they are needed? Confirm that the April 20 export includes the late-finalized cases accessioned through April 3.
- **Fitness for purpose:** can this analysis answer the laboratory's question? A single post-go-live group hides the difference between cutover and the later weeks.

For example, a correctly formatted time can pass a validity check and still fail an accuracy check if it records later data entry instead of accession. A blank field is a completeness problem; there is no value there yet to compare for accuracy.

Choose the main question each check addresses. Some problems affect more than one dimension, so explain your reasoning rather than treating the terms as entirely separate compartments.
