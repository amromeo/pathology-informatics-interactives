# Faculty guide: Dirty Data, Clean Decision

## Learning target

The learner should diagnose the missing-data mechanism, not merely name a data-quality dimension. Require them to explain how the defect changes the denominator and therefore the operational decision.

## Wrong paths worth discussing

- Attributing an abrupt dashboard change to analyzer speed without source evidence.
- Deleting the upgrade day while leaving converted records defective.
- Imputing event timestamps in a way that conceals delays.
