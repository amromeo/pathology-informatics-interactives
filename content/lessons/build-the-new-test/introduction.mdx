# Building and Validating a Laboratory Test

You are the pathology resident assigned to a microbiology test implementation. The laboratory is bringing influenza A, influenza B, and respiratory syncytial virus (RSV) testing in-house. The emergency department needs each organism shown separately in the electronic health record (EHR).

The laboratory information system (LIS) analyst copied an existing respiratory test to start the build in the test environment. A sample message reached the EHR successfully, but the report says “Respiratory panel: Detected copies/mL.” The procedure describes a qualitative assay, and the report does not identify the detected organism.

The microbiology director asks you to compare the request, procedure, and displayed report, then help specify the repair. The copied configuration also governs invalid runs, pending results, specimens, corrections, and message retries. Repairing the opening display alone will not confirm that the new test is ready.

Inspect the three source records, configure the result behavior, and run the eight report checks. Then prepare a release recommendation that separates technical testing from clinical and operational approval.


## What you will be able to do

- Validate the complete report before releasing a build.
- Review the approved build specification.
- Explain why “copy a similar test without a specification” is an incomplete approach.

Start by reading the case records. Make a choice before checking the explanation; you can revise it and test again.
