# Build the New Test

> **Synthetic project:** A multiplex respiratory assay must be built across ordering, LIS, interface, EHR display, procedures, training, and downtime workflows.

## Your task

Define the order name, component results, interpretations, units, internal controls, public fields, codes, validation, regulatory implications, environments, approvals, and post-go-live monitoring.

## Concept lens

A test build is a clinical information model implemented across systems. Technical completion does not establish clinically correct meaning or display.
