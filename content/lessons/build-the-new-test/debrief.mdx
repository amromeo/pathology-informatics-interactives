## Debrief: validate the complete report before releasing a build

### What happened in this case


The first report squeezed three viruses into one answer and carried units copied from a quantitative test. Arriving safely in the EHR did not make that report useful to clinicians.

The fixed definition keeps three named detected/not-detected results, shows no final value for pending tests, treats failed controls as an invalid run, and sends specimens outside the local procedure for review. It tells a correction apart from a new report, and a repeat send apart from another test.

The specimen rule belongs to this case's approved procedure; it says nothing about every respiratory assay. In the same way, “no units” is right for this detected/not-detected result, not a general rule for laboratory tests.

Eight passing checks show that eight cases behave as expected. They do not cover every patient identifier, time, permission, interface, outage or other use of the result. The readiness review adds clinical approval, checking the report in the EHR, procedures and training, and a controlled move to the live system with monitoring.

### Keep the definition up to date after go-live

Keep the request, the approved specification, the settings version, the test results, the sign-offs and the go-live record together. Record any later change to names, codes, specimen requirements, comments, result values and routing, and check which reports, procedures and training materials each change affects.

A procedure manual for the laboratory's information systems should cover day-to-day running and exceptions, interfaces and reports, who has access, quality checks, downtime and recovery, and how changes are controlled. Name a reviewer and set a review schedule. Retiring an old order also means checking saved order sets and how old reports can still be found.

US CLIA rules on reporting include getting reports reliably to where they are going, what a report must contain and how corrections are handled. Check the current rules and the laboratory's accreditation checklist; this exercise does not decide whether a laboratory meets them.

An order name tells the clinician what to order. The result names say what each individual result is. So a respiratory panel can be one order with several separately named detected/not-detected results.

For this build, look at each result's value, status and any comment in the chart. A pending result must never look like a negative one. The report also has to show which result was corrected and keep the link to the earlier report.

Keep a copy of the approved definition with the test records. The laboratory director can then compare the clinical request with the report clinicians will actually read, including failed runs and exceptions.

**Before go-live:** Which screen in the chart would you open to check that all three viruses are still named separately and that no copied units appear?

### Who does what

The LIS build analyst sets up the test and records the test results. Microbiology staff check the bench procedure. The microbiology director reviews what each result means with the emergency department and approves go-live.
