## Debrief: keep each finding attached to the right tumor

### What happened in this case

In TB-01, the image label says block A2, but the view showed it as A1. The image needs to go back to its documented block. TB-02 is already linked to the current lung biopsy and should stay as it is. In TB-03, the import swapped the last two digits of the patient's medical record number; the source laboratory confirmed the correct one. TB-04 is a variant report from an earlier colon specimen, and TB-05 holds the stage from that colon cancer. Keep those older records as history, separate from the lung case, and get the current findings.

Fixing these records is about veracity. It adds no storage and no speed. The load test is about volume and velocity, and it has to run overnight scanning and clinical viewing at the same time. Variety means keeping track of what each kind of data means and where it came from. Value depends on whether the view answers the board's question about the current tumor.

### Who does what

The LIS analyst and the archive team look into the import and the image links. The pathologist confirms which specimen each result came from and what the report means. The clinical team confirms which encounter holds the current stage. Researchers work from approved copies and write down how they chose their cases. Every correction is recorded; nobody quietly changes an identifier in the source system.

<summary>A closer look: follow the specimen as well as the patient</summary>

A tumor-board view brings together records made for different reasons. An image is linked to a block, a genomic report to a specimen and a stage to a clinical encounter. All three can carry the right patient identifier and still refer to different tumors or different episodes of care.

Trace one finding in the combined view back to where it came from. For an image, check the slide label, the block and the accession. For a genomic result, check the submitted specimen and the report date. Ask the clinical team which encounter the stage came from. Fix a wrong link without disturbing a current result that is linked correctly.

**At tumor board:** If the genomic finding did not seem to fit the slide on screen, which source record would you open first?
