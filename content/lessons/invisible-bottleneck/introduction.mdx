# Investigating Delayed Result Release

At noon, the chemistry supervisor reports that specimens delivered around
10:00 have taken much longer than usual to appear as final results. The
operations dashboard still shows a median receipt-to-release time of
**20 minutes**. A manager asks whether another analyzer is needed.

You are the resident assisting the supervisor and analytics team. The dashboard
was built from finalized LIS results. It opens in a web page whose clock shows
the current time, but its data come from a scheduled extract. Middleware review
events and unfinished accessions are stored in separate operational systems.

The review set contains 14 accessions received from 08:00 through 10:07 on
the same day: six earlier routine records and eight from the 10:00 delivery.
Inspect the source logs, update the extract, and link unfinished records.
Then compare time before and after analysis and propose a monitored intervention.
