# Faculty guide: Sending a Newborn Screening Report

## At a glance

Allow 35 minutes. Use individually or in a small group. Project the case records and the exercise controls; keep the answer key out of view until learners commit to a decision.

Learning objectives: match standards to the question they answer; read the receiver implementation guide; justify the first local check. PIER: 5.1, 5.2, 5.3.

## Run of show

| Minutes | Activity | Ask the group |
| --- | --- | --- |
| 0–7 | Read the case and records | What decision has the laboratory been asked to make? |
| 7–25 | Make, test and revise a choice | Which record supports your decision? What could fail? |
| 25–35 | Debrief and retrieval questions | How would you verify this in your own laboratory? |

## Expected answers


Allow 35 minutes. Ask the learner to explain why an accepted report is absent
from the program worklist before changing controls. The case specifies a
staging-and-routing architecture; do not teach that every HL7 acknowledgment
only establishes transport.

Expected replay: 5/8 initially; 8/8 after both terminology settings are repaired.
A condition-specific code for the overall report remains wrong. Switching to
identifier-only matching misroutes NB-04. Treating every message as new creates
a duplicate NB-05 and fails correction review for NB-06. Ask how these defects
could affect program follow-up even if all messages were successfully stored.

Assess the distinction among observation identity, answer concept, value set,
numeric units, and patient identity. Ask the resident to describe how the same
information could be represented in FHIR without implying that JSON alone
solves interoperability. Require a versioned interface agreement and an
identified person responsible for exceptions.

PIER alignment: 5.1–5.3. Harrison/API: Session 4 slides 3–6, 10–12, 16–21,
and 22–34. Discuss standards organizations, implementation guides, vocabulary,
and demonstrated clinical use.

Sources: [LOINC newborn-screening panel (54089-8)](https://loinc.org/54089-8),
[57130-7 and its example answer list](https://loinc.org/57130-7),
[46746-4](https://loinc.org/46746-4), and
[FHIR R4 Observation](https://hl7.org/fhir/R4/observation.html).
The routing rules and selected answer subset are this case's interface
agreement, not a universal public-health requirement. No diagnostic cutoff
is inferred from these codes.

For standards development, use the
[HL7 specification lifecycle](https://projectlifedashboard.hl7.org/specification-lifecycle/).
Ask the learner how a missing clinical concept should be raised, reviewed, and
adopted without changing the private meaning of an existing shared code.

## Common misconceptions

- “Whether any bytes were received.” Ask: what does the record actually establish? Structural validation cannot establish that both organizations understand the same test or value. Terminology and value-set agreement are needed.
- “Whether a message control ID exists.” Ask: which conclusion would still need evidence? Structural validation cannot establish that both organizations understand the same test or value. Terminology and value-set agreement are needed.
- “Assume the latest standard needs no local testing.” Ask: what must be checked before making the change? It defines required fields, supported values and acknowledgment behavior for this exchange.

## Discussion prompts

1. What supports the case decision? A strong answer includes a specific record and the distinction: match standards to the question they answer.
2. What would you check locally? A strong answer includes: read the receiver implementation guide, because it defines required fields, supported values and acknowledgment behavior for this exchange.
3. Who needs to participate? A strong answer includes a public-health interface lead and separates technical work from clinical approval.

## Group variant

Assign laboratory director, LIS analyst, laboratory operations and clinical service roles. Add clinical informatics and a patient advocate when considering ordering or chart use. Ask each person to state one requirement, one risk and the evidence needed before approval. The director then summarizes what can proceed and what must be resolved.

## Assess transfer

Map a public-health report field to its message rule, terminology and receiving-team validation. A strong response names the record, responsible person, first check and an unresolved risk. Use the three learner retrieval questions to distinguish an unsupported shortcut from a reasoned decision.
