### Keep the cases that should behave differently

The first encounter is only one test. Run your design against a collecting nurse, a patient with no history, an older report, an unusable report, a pending order, a documented reason to repeat and a result exactly 90 days old.

In this exercise, the rule uses the collection time of a final report and counts exactly 90 days as inside the window. A pending order has to be described as pending, without suggesting a final result exists. The documented exception still shows the earlier information and still lets the clinician go ahead.

The checks test the approved specification for how the guidance is delivered. They do not show that it works clinically. A suggestion beside the order and a soft stop can both leave the decision with the clinician, but the soft stop costs more attention. Explain why an interruption is needed before choosing one. Changing the design clears the last test result, so run the encounters again after each change.
