# Designing Repeat-Test Guidance

You are the pathology resident working with the laboratory director and the electronic health record (EHR) team. Last month, the team added guidance for repeat hemoglobin A1c (HbA1c) orders. Clinicians report that the message arrives after they have signed the order. Collection staff receive it too, even though they did not request the test.

The laboratory director asks you to examine the ordering audit, compare it with the prior laboratory report, and redesign the guidance. The clinical question is whether available information should be reviewed before another test is ordered. The rule cannot determine the answer without the clinician's assessment.

The local specification asks for review when a usable final result was collected within 168 hours, or another order is still pending. This window is a case-specific review trigger, not a universal recommendation about how often HbA1c should be measured. A documented clinical reason must allow a repeat.

Start with the records. Identify who received the message, where it appeared, and whether the order was still editable. Then build a different design and test it against eight encounters.
