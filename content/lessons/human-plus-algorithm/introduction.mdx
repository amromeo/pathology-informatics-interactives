# Reviewing a Mitosis Detection Tool

Dr. Rao is evaluating a tool that marks possible mitotic figures in a defined tumor area. The pathologist must review those locations, search the rest of the area, and record the final count. The tool does not assign a diagnosis, grade, or prognosis.

The vendor's sensitivity figure does not tell Dr. Rao how many false marks require review or what happens when a reader sees an empty overlay. You will inspect candidate locations, change the marking threshold, compare site-specific errors, and review a separate reader study and monitoring report.

The candidate list contains 12 selected locations from a development review: five reference mitotic figures and seven nonmitotic locations. Two pathologists established the reference labels by consensus. All 12 locations remain in the exercise. This deliberately small selected set supports arithmetic and error inspection; it is not an estimate of slide-level clinical accuracy.
