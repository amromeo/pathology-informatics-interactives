# Human + Algorithm

> **Synthetic case:** A mitosis-assist tool has high sensitivity, but produces many false marks, increases review time, and appears to make negative overlays unusually reassuring.

## Your task

Distinguish image processing, pattern recognition, diagnosis, and prognosis. Adjust the operating threshold and design human oversight and monitoring that measure the deployed human-plus-model system.

## Concept lens

Changing a model threshold changes both statistical performance and human workload. Clinical performance emerges from the interaction between data, model, interface, user, and workflow.
