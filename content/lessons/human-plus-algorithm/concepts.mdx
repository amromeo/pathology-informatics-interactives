## Ask what the software output means

Image processing changes or measures the pixels, for example separating stains or judging focus. Pattern recognition suggests a category or a location. A cell counter also has to decide which cells belong in the denominator. Morphometry measures shapes and sizes; mitosis detection suggests places to look. A diagnostic classifier and a prognostic model answer different questions: what the patient has, and what is likely to happen. Each needs its own reference answers, patient group, end point and validation.

Here the score ranks possible mitoses. It is not the probability of cancer or of any outcome, and it is not even a reliable probability that the spot is a mitosis. A **threshold** marks locations whose scores are at least the selected value; a score exactly equal to the threshold is included.

A true positive is a reference mitosis that is marked. A false negative is a reference mitosis left unmarked. A false positive is a nonmitotic location that is marked. A true negative is a nonmitotic location left unmarked. Look at the individual locations as well as the totals.

Sensitivity divides marked reference mitoses by all reference mitoses. Specificity divides unmarked nonmitotic locations by all reference nonmitotic locations. Positive predictive value divides true marks by all marks. If there are no marks, that last fraction has a zero denominator and is undefined, not 100%.

These numbers describe this hand-picked list only. A real evaluation also needs an area chosen in advance and a way to find mitoses the tool never suggested. Specificity depends on how the non-mitotic locations were picked, so do not stretch this seven-location denominator to every cell on a slide.

Sites A and B each provide six locations, with three and two true mitoses. Compare their errors, then ask about staining, preparation, scanner and the kinds of cases. Small differences between groups this size are clues to follow up, not reliable estimates. A threshold chosen on this set needs testing on separate cases; adjusting it again and again on the final test set would spoil that test.
