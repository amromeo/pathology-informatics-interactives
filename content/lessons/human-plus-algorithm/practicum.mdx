# Local practicum

With a pathologist supervising an approved image-analysis workflow, identify the actual task, input preparation, area or cell denominator, software version, threshold, output, and human review responsibilities. Ask how false negatives can be found and how failed analyses are handled.

Review an approved monitoring plan for final reader errors, subgroup case mix, workload, and change control. If no tool is deployed, write a proposal for an independent evaluation using approved local training images. Do not install a tool or change a clinical threshold for this exercise.
