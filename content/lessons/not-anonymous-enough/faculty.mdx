# Faculty guide: Not Anonymous Enough

## At a glance

Allow 25 minutes. The case follows recovery from the April 18 outage. Jordan prepared a fixed 18-patient file; the six downtime specimens are separate examples. Residents work with Dr. Chen and Priya to inspect a proposed export before release. Teach PIER 3.2 and 3.4 through field combinations, transformations and disclosure review.

## Run of show

| Minutes | Work | Ask |
| --- | --- | --- |
| 0–5 | Read how the export and key were prepared | Where could a recipient find a patient's identity? |
| 5–10 | Filter the original file | What does one matching row prove, and what does it leave unknown? |
| 10–18 | Change fields and protect the key | Why can a useful change leave k unchanged? |
| 18–25 | Classify, test a proposal and debrief | Which details does the research need, and who approves the disclosure method? |

## Expected reasoning

The original file is coded and reidentifiable. The shared lookup key directly connects codes to identity. A combination of known patient details provides another possible route. The visible linkage code and the separate key must not be described as the same object.

Breast carcinoma selects three rows; adding ZIP 02108 selects NR-001. The diagnosis is common in practice but appears in only three rows here. The file is a selected patient-description extract, not a representative disease-frequency sample or a table of all completed tests.

Broadening ZIP and diagnosis creates groups of **4, 4, 5 and 5**, so the minimum is **4**. Date generalization leaves these group counts unchanged because every admission date was April 18. Restricting the key also leaves k unchanged because neither the key nor the unique row labels/codes are part of the five-field comparison.

Every single transformation still leaves a unique combination somewhere in the file. ZIP alone leaves NR-004 distinguishable from the breast-carcinoma rows; diagnosis alone leaves detailed ZIPs. Have residents inspect the transformed rows instead of inferring a privacy conclusion from the green counter.

## Release decisions

The public-release shortcut passes only the key-control check when the key has been restricted. A confidentiality promise alone does not specify the full approved disclosure method. The preferred proposal requires all three field changes, key restriction, purpose, recipient and agreement before its five exercise checks pass.

Those checks implement this case's conservative proposal. They do not define all lawful research releases. A limited data set may retain dates and ZIPs if its requirements are met. When that detail is needed, the investigator and Priya should review that route instead of assuming that every lawful file must use the three transformations.

The known cohort is an important remaining issue: everyone who knows the file contains April 18 admissions can infer the date from that context. The application also does not verify Census population counts for the ZIP prefixes or the derivation of retained codes. All five checks passing means the proposal is ready for documented review, not that the institution has established deidentification.

The patient-description fields shown here cannot answer whether tests were completed or critical results communicated. Ask the investigator to specify the outcome fields and their time requirements. Any added fields require review too.

## Common misconceptions

- **No names means anonymous:** ask what the lookup key and the diagnosis-plus-ZIP combination reveal.
- **A larger k proves HIPAA compliance:** ask which fields were counted and which legal and contextual checks remain.
- **Protecting the key changes the rows:** ask the learner to compare the preview before and after changing key access.
- **Dates must always be removed from research:** ask whether the proposed method is Safe Harbor, Expert Determination or a limited data set.
- **Breast carcinoma is rare:** distinguish three rows in this selected file from disease frequency in the hospital or population.

Assign Jordan to explain the export, the investigator to justify each requested field, and Priya to identify the required review and agreement. Have the resident explain the proposed release to each person. The local practicum uses a field list and local policy without copying patient records.
