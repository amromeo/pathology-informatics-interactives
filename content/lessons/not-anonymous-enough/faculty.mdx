# Faculty guide: Not Anonymous Enough

Ask learners to explain how the combination of fields—not just one field—changes reidentification risk. Removing the linkage key is a real safeguard, but it does not make detailed dates, geography, and a rare cohort suitable for public release.

Start with Ewing sarcoma: three records remain. Adding ZIP 02108 isolates NR-001. Then compare one transformation with all three: only the complete set raises the smallest displayed group to four in this teaching table. Sequestering the key alone leaves that group size unchanged. Ask what research detail each transformation removes and whether the approved research question still can be answered.

Run the public-release shortcut and inspect its partial credit: separating the key passes one check but leaves four failures. For the controlled release path, the workbench must also document purpose, recipient, and agreement. A passing result means the proposal is ready for documented privacy review; it does not authorize release. Reset and repeat with one safeguard missing to show why selecting the preferred narrative answer alone is insufficient.

Make the regulatory distinction explicit: the HIPAA Privacy Rule recognizes Safe Harbor and Expert Determination as deidentification methods. A limited data set remains protected health information and requires an appropriate purpose, recipient, and data use agreement. Local policies and legal review remain authoritative; this exercise is educational and not legal advice.
