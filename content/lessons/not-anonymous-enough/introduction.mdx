# Not Anonymous Enough

> **Story so far:** After North River University Hospital's April 18 outage, Dr. Maya Chen, a pathology informatics fellow, and Jordan Ellis, a laboratory information system analyst, helped reconcile paper records with the restored system; this case uses a fixed post-incident record, so earlier simulated choices do not change the export reviewed here.

## Case setup

North River University Hospital is a Level I trauma center. Two weeks after the outage, the quality office asks Dr. Chen to help Priya Nair, the hospital privacy officer, review a research export assembled from the outage-period reconciliation records. Jordan extracted the requested fields from the laboratory information system. The investigator wants to study how prolonged downtime affected test completion and critical-result communication.

The file contains no names or medical record numbers, but it retains exact admission dates, full five-digit ZIP codes, rare diagnoses, and a linkage key stored in a shared project folder. The review must determine what the remaining fields could reveal, which institutional release pathway may apply, and what must change before the file leaves the hospital.

## Your task

Inspect which identifiers and distinguishing details remain, classify the export as presented, and choose a release path. Then run that path against field-minimization, linkage-key, uniqueness-risk, recipient, and confidentiality checks.


## What you will be able to do

- Distinguish removing names from satisfying a disclosure method.
- Ask which disclosure method was approved.
- Explain why “delete names and send the remaining file” is an incomplete approach.

Start by reading the case records. Make a choice before checking the explanation; you can revise it and test again.
