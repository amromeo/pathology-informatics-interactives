### What the uniqueness counter means

First ask a plain-language question: what is the smallest number of records that share the same displayed combination of birth year, sex, geography, admission period, and diagnosis category? The file is *k*-anonymous, with *k* equal to that smallest group size. A value of 1 means at least one displayed combination belongs to only one record in this 18-row file.

In this lesson, *k*-anonymity is only a visible signal of uniqueness in the table. It does not show that data are deidentified under the Health Insurance Portability and Accountability Act (HIPAA). Federal guidance describes two HIPAA deidentification methods: Safe Harbor and Expert Determination. A limited data set is a separate release pathway; it remains protected health information and requires an eligible purpose, an appropriate recipient, and a data use agreement.

The linkage key is also separate from the counter. Moving it to a restricted location is an important safeguard, but it does not change which displayed field combinations are unique.

Safe Harbor removes every five-digit ZIP code. The first three digits may remain only if the combined area has more than 20,000 residents; otherwise use 000. A retained study code must not be derived from patient information, and its reidentification key must not be disclosed.

### Choose the release pathway before exporting

Public data are released without access controls, so the institution must determine that the release is appropriately deidentified and low risk. Deidentified data meet HIPAA Safe Harbor or Expert Determination and are no longer protected health information under HIPAA. Safe Harbor removes specified identifiers and requires no actual knowledge that remaining information identifies a person. Expert Determination uses a qualified expert's documented assessment of a very small identification risk.

Coded data replace identifiers with a code whose key is held separately. Coding alone does not meet either deidentification method. A research authorization or an institutional review board/privacy board waiver addresses a different question from whether a file is deidentified. Ask the privacy office about records covered by 42 CFR Part 2 and applicable state protections before including them.
