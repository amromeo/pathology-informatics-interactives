### Follow the four records

The report definition tells the LIS which reference interval to display. The written protocol records the director's intended ordering sequence. The saved reflex rule contains the conditions the program actually tests. Finally, the order record identifies what the program did for a particular accession and which revision it used.

Follow TH-01 across these records. Its report uses the new interval, **0.27–4.20 mIU/L**. The saved rule is revision 8, whose lower threshold is still **0.40**. The order record names revision 8 when documenting the FT4 order at 07:18.

Updating one definition leaves the other at its saved value until staff change it. That is how the displayed interval and the ordering action can disagree. In this case the director explicitly approved both the new interval and the new ordering thresholds.

### Check which records the rule applies to

Before comparing TSH with a threshold, the program checks the patient's age and requested order type. This sequence applies to **adults aged 18 or older** whose clinician requested **TSH with reflex**. A TSH-only order or a pediatric record is outside this rule's scope.

Next, the program requires a **final numeric TSH**. Staff review a missing or preliminary result before deciding about further testing. Treating a blank as zero would cause the program to test a concentration that was never reported.

The thresholds belong to this laboratory's approved adult protocol. Other populations and clinical questions may require different testing arrangements. Keep that scope in view when testing the records below.

### Test values on both sides of a boundary

The approved instruction is to add FT4 when TSH is **below 0.27 OR above 4.20 mIU/L**. OR allows either condition to trigger the next step. Values exactly equal to a boundary remain inside this protocol's interval.

### Check for an FT4 already on the accession

After a threshold condition is met, the program looks for a pending or completed FT4 linked to that accession. If one exists, the action is **Use existing FT4**. The pending test can continue, or its completed result can be used, without creating a second order.

For example, TH-08 has a TSH of 0.10 and an FT4 already complete. Its low TSH meets the threshold condition. The linked FT4 then prevents a duplicate. TH-09 tests the same situation with a pending FT4.

Read the accession's linked-order information to identify the pending or completed FT4 that the rule will use.
