# Faculty guide: Updating a Thyroid Reflex Rule

Allow 30 minutes. The resident should explain an additional FT4 using the saved rule, repair its lower threshold and account for all expected actions. The lesson addresses PIER 4.3, 4.5, 4.2 and 8.2.

## Run of show

Use about 6 minutes for the case and terms, 7 for the four records and worked comparison, 10 for the replay, and 7 for affected cases and monitoring.

## Explain the separate definitions

Ask the resident to identify the report definition, approved protocol, saved rule and order record. For TH-01, the report definition contains 0.27–4.20 mIU/L. Revision 8 contains a lower threshold of 0.40, and the order record names that revision.

Have the learner compare 0.30 with each threshold aloud. It is below 0.40, above 0.27 and below 4.20. The old lower condition creates the order; neither approved condition calls for one.

The director explicitly approved both the interval and the adult reflex protocol. An assay's reference interval does not automatically determine an appropriate ordering sequence. Keep the clinical scope tied to this case.

## Test the complete protocol

Expected settings: lower 0.27, upper 4.20, strictly outside the limits, adults with TSH-with-reflex orders, final numeric results, and reuse of pending or completed FT4s on the same accession.

The original configuration matches 10/13 and adds five orders. Changing only the lower threshold matches 13/13 and adds two. The removed additions are TH-01, TH-02 and TH-04; the retained additions are TH-03 and TH-07.

Ask the learner to predict these changes before replaying:

- Including exact boundaries adds unintended FT4s at TH-04 and TH-06.
- Disabling duplicate prevention creates extra orders at TH-08 and TH-09.
- Bypassing age/order scope changes TH-11 and TH-12.
- Allowing preliminary numeric results changes TH-13. Missing TSH still requires review.

The original investigation records remain fixed while controls change the proposed configuration. The revised results and final recommendation clear after a setting changes.

## Teach the denominator

There are 13 selected records: nine eligible final numeric adult reflex results, two requiring review and two outside scope. Two of the nine eligible accessions already have a linked FT4.

Ask how selecting only newly added FT4s would hide missed additions. For routine monitoring, specify a period and examine all eligible accessions, comparing expected and actual actions. Keep exceptions visible and report their handling separately.

The chosen records test a mechanism and its boundaries. Their order count is not a hospital-wide utilization estimate.

## Common misconceptions

- **The correct display proves the rule was updated.** Ask which saved definition the order program read and which revision appears in the order history.
- **Fewer orders proves improvement.** Widen the thresholds enough to miss TH-03 and TH-07, then compare the count with the expected actions.
- **A value equal to the threshold is below it.** Use 0.27 and 4.20 to distinguish strict and inclusive comparisons.
- **A pending FT4 permits another order because no result exists yet.** Ask what work the first order already represents.
- **Every affected FT4 should be cancelled.** Review order status, completed results and the clinical situation before deciding on an approved correction.

## Follow the change into other work

Ask for a list of related definitions and records: report interval, ordering rule, order type, population, status, FT4 code, duplicate check and monitoring report. A useful handoff names the changed version, expected and observed actions, affected accessions, reviewers and follow-up responsibilities.

The additional questions ask for a denominator and outcomes to monitor. A complete response includes missed indicated orders and unnecessary additions, with attention to duplicates, unresolved exceptions and reporting delays.

## Teaching sources

[API's clinical decision support slides](https://www.pathologyinformatics.org/assets/lms/jimharrison/PathInformatics%207%20CDS%20slides.pptx), by James H. Harrison, Jr., and Ronald Jackups, provide background on result-dependent orders. Use session 7, slides 17 and 27, alongside the configuration and change-testing material in sessions 3 and 9. Ask learners to identify the intermediate result and the order that depends on it.

The [American Thyroid Association's thyroid function test explanation](https://www.thyroid.org/thyroid-function-tests/) provides optional clinical context for interpreting TSH and FT4. The numerical thresholds, adult scope and reflex sequence in this lesson are the case laboratory's approved policy.
