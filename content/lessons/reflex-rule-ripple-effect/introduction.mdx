# The Reflex Rule Ripple Effect

> **Synthetic case:** A thyroid assay’s reference interval changes, but the dependent free-T4 reflex rule retains its former threshold.

## Your task

Map the assay definition, display, reflex logic, downstream order, utilization report, and change-control record. Find which dependency escaped the go-live scope.

## Concept lens

A test definition is a network of clinical and technical dependencies. Updating the visible interval does not update hidden rules automatically.
