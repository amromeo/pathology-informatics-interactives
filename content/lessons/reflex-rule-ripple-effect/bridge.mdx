### Account for the 13 records

The [accession replay](#reflex-replay-heading) contains **13 selected records** from the morning investigation. Of these, **nine** have final numeric TSH results on adult TSH-with-reflex orders. Two of those nine already have an FT4 pending or complete. Two other records need review, and two fall outside this adult reflex rule.

The original settings create **five new FT4 orders**. The approved settings create **two**, at TH-03 and TH-07. TH-01, TH-02 and TH-04 account for the three additional orders under the original lower threshold. TH-08 and TH-09 use their existing FT4s and do not add to the new-order count.

Read the action for each accession before judging the totals. A setting that blocked every FT4 would lower the total but miss the tests that were needed at TH-03 and TH-07. Matching the approved actions means getting the needed additions, existing tests, review cases and out-of-scope records all right.

### Choose a monitoring group before counting

Once the rule is in use, the team needs a set review period and a list of the accessions it should apply to. For example, it could review all adult TSH-with-reflex accessions with final numeric TSH results during that period.

For every accession on that list, work out what the approved rule should have done and compare it with what actually happened. That shows up unnecessary additions, missed additions and duplicates. A list of only the new FT4 orders would leave out the patients whose FT4 should have been added but was not.

Use the number of eligible accessions as the denominator when reporting how often those errors happen. Count missing or preliminary results awaiting review, and records outside the rule, separately. The 13 records in this exercise were picked to show particular situations; a routine error rate needs every eligible accession in the set period.

### Review the other settings affected by a change

A **dependency** is an item that uses the changed result or definition. In this case, list the displayed interval, reflex thresholds, order type, age restriction, result status, FT4 order code and duplicate check. Then check that an added order is linked correctly and reaches the right worklist.

The same approach applies to calculated results. Changing a creatinine assay can affect eGFR; changing the measurements used to calculate LDL cholesterol can affect that reported result. The team needs to know the inputs, units, equation and report fields involved before deciding what to test.

### Follow up on orders already created

Chemistry staff and the laboratory director review the real patient accessions the old rule affected. For each, they check whether the added FT4 is still pending, whether testing has started, whether a result is already out and whether a clinical review supports doing anything more.

Record any approved correction and any message to clinicians, and keep the original history. Cancelling everything at once would ignore tests already done and clinicians who may now need the result. The analyst records the new rule and the testing; the director reviews the intended ordering sequence and the plan for the affected cases.
