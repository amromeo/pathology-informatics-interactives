### Other standards cover other parts of the report

An **orderable** is something a clinician can order. Ordering a panel may lead to several results being measured and reported. An **observation** says what was measured or assessed. Its **value** is the answer, and its **unit** says what quantity the number describes, where there is one. A report brings those observations together with an interpretation and context.

For example, an estrogen-receptor result, its percentage, the % unit and the pathologist's interpretation are separate pieces of data. The breast panel order does not carry all of those meanings. A billing entry records a service for administrative purposes; it cannot confirm what a particular tumor's result was.

### Match each standard to the job

**LOINC** identifies tests, observations and related clinical information. **SNOMED CT** represents detailed clinical concepts, including findings. **UCUM** writes units in a form computers can read. These can all be used together in one record; picking one does not do away with the others.

**ICD** classifies diagnoses for particular administrative and reporting purposes. **CPT** describes services for US billing. The right edition, the service documented and the submission rules all matter; this exercise does not assign a billing code.

**DICOM** describes medical images and the information stored with them, including whole-slide microscopy images. **CAP cancer protocols** set out the structured reporting items for each cancer and procedure. Neither an image format nor a report template is a general clinical vocabulary, though report items may use terminology codes inside them.

A short label such as HER2 does not tell you the specimen, the method or the kind of result. An immunostain interpretation and a gene-amplification result cannot be treated as the same just because both labels say HER2. If the local test list does not say what the assay is, get that from the person responsible for the assay before accepting a mapping. Asking for the missing assay definition is the right decision here.

### Write down what the mapping claims

Record the local code and its definition, the code system and code you mapped to, the terminology version, how closely they match, the reviewer, the date and who will use the result. A broader or narrower code may be fine for a particular purpose, but it is not automatically an exact match. Sharing a LOINC code does not show that two local assays give interchangeable results; that needs its own evidence.

Test typical values, units, interpretation categories and missing fields in the receiving system. A valid code can still produce a wrong record when it is paired with the wrong value, specimen or unit.
