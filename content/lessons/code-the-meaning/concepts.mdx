### What problem does LOINC solve?

A local test code only works inside the laboratory that made it. Another hospital cannot reliably tell what it means from a number or an abbreviation. Different names can describe the same test, and the same name can hide a different specimen, property or method.

**LOINC** stands for **Logical Observation Identifiers Names and Codes**. It provides shared codes and definitions for tests and observations. In this exercise, it answers "Which glucose test is this?" The number answers "What was the result?", and the unit says what that number is a measure of. These are separate fields.

A **mapping** is a checked link between a test in the local list and a standard code. The analyst sets up the link; laboratory staff confirm what the local assay measures and reports. The local code can be kept alongside the LOINC code. A receiving system can then use the shared, checked code to find results even when the local names differ.

Adding a code does not rename every local test, convert any values, or show that two assays give interchangeable results. Showing a patient's results as a trend also needs matching units, methods and specimens, and someone to interpret them. A matching code is never a reason to skip those checks.

### Read the definition, not just the code

On the LOINC website, look at the fully specified name or the Part Model. Six parts describe the test:

| Part | Question to ask about this glucose result |
| --- | --- |
| Component | Is glucose being measured? |
| Property | Is the amount given as mass per volume or moles per volume? |
| Time | Is this a single point in time (Pt), rather than a timed collection? |
| System | Is the specimen serum/plasma (Ser/Plas), rather than urine or something else? |
| Scale | Is the answer a number (Qn), rather than a category? |
| Method | Does the code name a method, or leave it unspecified? |

A blank method part means the code does not specify a method; it does not mean the laboratory used none. MCnc means mass concentration; SCnc means substance concentration. For these records, mg/dL and mmol/L show that difference in property. A real LOINC code can still be the wrong one for a particular test.

### Look up the two glucose codes

Open <a href="https://loinc.org/search" target="_blank" rel="noopener noreferrer">SearchLOINC</a> in another tab and search for **glucose serum plasma**. Compare a mass-per-volume code with a moles-per-volume code. The search may ask you to sign in to a free LOINC account. If that gets in the way, open these public pages directly: <a href="https://loinc.org/2345-7" target="_blank" rel="noopener noreferrer">candidate A</a> and <a href="https://loinc.org/14749-6" target="_blank" rel="noopener noreferrer">candidate B</a>. The job is still to read and compare their definitions, not to take the first search result.

Keep the local test list in view. Write down the code for Hospitals A and B and the code for Hospital C, the partner hospital in Canada, then the property and the five shared parts you found on each code's page. In a real mapping log, also check the code's status on the website and record the LOINC release and the date you checked. The lesson checks the comparison you enter; it cannot tell whether you visited the website.
