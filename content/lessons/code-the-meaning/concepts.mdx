### What problem does LOINC solve?

Local test identifiers work inside the laboratory that defines them. Another hospital cannot reliably infer their meaning from a number or an abbreviation. Different labels can name equivalent observations, and identical labels can hide different specimens, properties, or methods.

**LOINC** stands for **Logical Observation Identifiers Names and Codes**. It provides shared identifiers and definitions for observations. In this exercise, it answers “Which glucose observation is this?” The numeric result answers “What was the measured value?” and the unit supplies its quantitative meaning. These are separate fields.

A **mapping** is a reviewed association between a local catalog entry and a standard term. The analyst configures that association; laboratory staff verify what the local assay measures and reports. The local code can be retained alongside the LOINC code. A receiving system can use a verified shared identifier to find observations despite different local names.

Adding a code does not rename every local test, convert a value, or prove that two assays are analytically interchangeable. A patient trend also needs compatible units, methods, specimen context, and appropriate interpretation. Never drop those checks merely because the code matches.

### Read the term, not just the code

On the LOINC website, inspect the fully specified name or Part Model. Six dimensions describe the observation:

| Dimension | Question to ask about this glucose result |
| --- | --- |
| Component | Is glucose being measured? |
| Property | Is the amount expressed as mass per volume or moles per volume? |
| Time | Is this a point-in-time measurement (Pt), rather than a timed collection? |
| System | Is the specimen serum/plasma (Ser/Plas), rather than urine or another material? |
| Scale | Is the answer quantitative (Qn), rather than a category? |
| Method | Does this term specify a method, or leave it unspecified? |

A blank method part means that the term does not specify one; it does not mean the laboratory used no method. MCnc denotes mass concentration; SCnc denotes substance concentration. For these records, mg/dL and mmol/L reveal that property difference. A valid LOINC number can still be the wrong mapping for a particular record.
