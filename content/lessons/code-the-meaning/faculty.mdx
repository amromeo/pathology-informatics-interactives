# Faculty guide: Why Laboratory Results Need LOINC

## At a glance

Allow 50 minutes. Use individually or in a small group. Project the case records and the exercise controls; keep the answer key out of view until learners commit to a decision.

Learning objectives: map a laboratory observation using its full definition; compare specimen, units, method and timing; justify the first local check. PIER: 5.3.

## Run of show

| Minutes | Activity | Ask the group |
| --- | --- | --- |

## Expected answers


Allow 45–50 minutes, including website lookup. Do not begin with a list of acronyms. Ask: “How can the receiving system know which results belong together when each laboratory uses its own names?” Have learners explain both failures in the opening records: A/B have different names for the same observation definition, while A/C share a name but differ in property.

### Sequence and answer key

1. Choose comparison of catalog definitions and shared observation identifiers. Retain local identifiers, values, and units; do not claim analytical equivalence from the examples.
2. Explain LOINC in the learner's own words before expanding its name. It identifies an observation independently of a local abbreviation. It does not itself supply the result or convert units.
3. Open SearchLOINC and search for glucose serum plasma. Account access may be required. The linked public candidate pages provide an alternative, so access setup should not consume the session. Ask learners to point to the actual term definition; the software cannot prove an external lookup occurred.
4. Record 2345-7 for A/B and 14749-6 for C. Shared fields: Glucose, Pt, Ser/Plas, Qn, method unspecified. Properties: MCnc for A/B; SCnc for C. A blank method does not mean no method was used. Ask about term status, release, and review date in a real mapping record.
5. Seven purpose answers: LOINC, SNOMED CT, UCUM, ICD, CPT, DICOM, CAP protocol. These are answers for the named uses, not absolute partitions of the standards' domains.
6. Mapping answers: 2345-7; 14749-6; obtain the HER2 assay definition; retain the panel order and map its components.
7. Literature answer: audit locally and distinguish denominators. Urine transfer answer: reject the serum/plasma assignment and obtain a specimen-matched term with the remaining dimensions verified.

### Check understanding beyond code recall

Ask the learner to explain LOINC without using the word “code”: “It tells another system which observation this result represents despite our local naming.” Then ask why the same numeric result or a recognizable abbreviation is insufficient. A shared LOINC term still does not establish analytical comparability or permit unvalidated value conversion.

The site checks the code pair and seven comparison fields together. Correct code numbers with the wrong specimen, scale, time, or method interpretation do not complete the lookup. Changed answers clear prior review feedback; reset clears all decisions. The debrief remains available before completion.

### Interpret the literature carefully

Stram et al. (2020) invited 1,916 laboratories in CAP coagulation/cardiac-marker surveys; 90 responded (4.7%). They reported 54 incorrect codes among 275 submitted codes (19.6%). Low response and selected tests limit external validity. Axis-error counts overlap: do not add them as if each were a distinct incorrect code.

McDonald et al. (2023) assessed 179,537,986 mapped quantitative results, representing 3,029 tests in two PCORnet DataMarts. The 4.6% figure is result-weighted. It is not an estimate that 4.6% of laboratories or 4.6% of all unique catalog mappings were incorrect. Avoid comparing it directly with the CAP code-level percentage or claiming a temporal improvement. Neither study estimates this institution's error rate. These summaries are based on the indexed abstracts; no unsupported subgroup inference is required for the lesson.

### Topic 5 continuity

The critical-flag lesson distinguishes receipt from retained meaning. The newborn-screening lesson introduces a shared observation identifier separately from its answer and patient identity. This lesson explains why that identifier is needed and how to verify it. The queue lesson then asks whether downstream records are current, complete, and correctly linked. Preserve those distinct questions rather than implying that one terminology repair makes a dataset trustworthy.

PIER alignment: 5.3. Harrison/API: Session 4 slides 16 and 22–32.

## Common misconceptions

- “The shortest matching display name.” Ask: what does the record actually establish? Component, property, timing, specimen, scale and method where relevant distinguish observations. Similar display names are insufficient.
- “The code used at a neighboring hospital.” Ask: which conclusion would still need evidence? Component, property, timing, specimen, scale and method where relevant distinguish observations. Similar display names are insufficient.
- “Choose the most common code from a search.” Ask: what must be checked before making the change? A terminology decision must describe what was actually measured before a code is selected.

## Discussion prompts

1. What supports the case decision? A strong answer includes a specific record and the distinction: map a laboratory observation using its full definition.
2. What would you check locally? A strong answer includes: compare specimen, units, method and timing, because a terminology decision must describe what was actually measured before a code is selected.
3. Who needs to participate? A strong answer includes a terminology steward and section director and separates technical work from clinical approval.

## Group variant

Assign laboratory director, LIS analyst, laboratory operations and clinical service roles. Add clinical informatics and a patient advocate when considering ordering or chart use. Ask each person to state one requirement, one risk and the evidence needed before approval. The director then summarizes what can proceed and what must be resolved.

## Assess transfer

Prepare a terminology review for one assay with its specimen, method, units and intended use. A strong response names the record, responsible person, first check and an unresolved risk. Use the three learner retrieval questions to distinguish an unsupported shortcut from a reasoned decision.
