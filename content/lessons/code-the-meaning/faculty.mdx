# Faculty guide: Reviewing Laboratory Terminology Mappings

Allow 35 minutes. Begin with the breast-report objects before introducing
the glucose counterexample. Ask learners to explain how an order, observation,
answer, unit, report, and service differ. Avoid teaching a rigid one-standard-
per-domain rule: standards overlap, and this workbench names a specific use
for each choice.

Seven purpose answers: LOINC, SNOMED CT, UCUM, ICD, CPT, DICOM, and CAP protocol.
Four mapping answers: 2345-7; 14749-6; defer pending assay definition; retain
order identity and map components. Ask the learner to defend the last two
without proposing a guessed code.

A strong explanation identifies mass versus substance concentration and
states that code assignment does not perform unit conversion. Challenge
the assumption that a shared LOINC code proves assay interchangeability.
Ask what the destination should do with records awaiting mapping review.
