## Debrief: map a laboratory observation using its full definition

### What happened in this case


LOINC supplies a common way to identify an observation when local names and identifiers differ. Hospitals A and B can map their differently named serum/plasma mass-concentration glucose observations to **2345-7**. Hospital C, a partner hospital in Canada's moles-per-volume observation maps to **14749-6**. Assigning a shared code does not convert 5.5 mmol/L to another unit or confirm assay interchangeability.

The website lookup required more than copying a number: glucose, property, point-in-time, serum/plasma, quantitative scale, and the unspecified method part had to fit the local records. The urine transfer case fails the specimen comparison even though glucose and mg/dL look familiar.

In the later review, TM-01 supports 2345-7 and TM-02 supports 14749-6. TM-03 needs its assay definition. TM-04 is an order whose component results need separate mappings. Deferral is a responsible completed decision when the evidence is missing.

LOINC identifies the observation; the value and unit remain separate. SNOMED CT can represent a clinical finding, UCUM expresses units, ICD classifies diagnoses, and CPT represents services for the named administrative use. DICOM imaging objects and CAP reporting structures solve different problems. These standards can work together; none substitutes for all the others.

The studies document mapping errors with different denominators. They justify checking local mappings, not assuming that a published percentage applies here. A valid code is not evidence that the local assignment is correct. Explain what the source means, what the target means, and why they match before approving the exchange.

This connects the Topic 5 lessons: a message may arrive yet lose a critical flag; an observation and its answer may require separate mappings; a mapping needs source evidence; and downstream analysis still requires complete, current, correctly linked records.

<summary>A closer look: explain why the candidate term fits</summary>

Start with the local observation: what was measured, in which specimen, over what time, and how the result is expressed. Then compare those details with the candidate LOINC term. A familiar test name is a useful starting point for a search, but it leaves those details to be checked.

The serum/plasma glucose examples use different properties for mass concentration and amount of substance per volume. The urine example changes the specimen. A shared code does not perform a unit conversion, and two assays still need clinical review before their results are treated as interchangeable.

Keep the supporting test definition with the approved mapping. When a local assay changes, staff can return to that definition and check whether the mapping still describes the reported observation.

### Who does what

Work with a terminology steward and section director. The person making a technical change should document the test evidence; the responsible clinical or operational lead approves the intended use.

### Connection to PIER 5.3

The case asks you to map a laboratory observation using its full definition using laboratory records and explain the consequence of your choice.
