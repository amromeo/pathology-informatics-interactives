### Explain the decision before approving the feed

Complete both reviews. The seven object decisions establish purpose; the four
mapping decisions test whether the supplied source definition supports a
particular assignment. A wrong choice reveals its consequence beside that
record, and you can revise it before running the review again.

For the actual feed, involve the assay owner, terminology specialist, registry
team, and laboratory leadership. Check that a deferred mapping is visibly
queued for resolution rather than silently omitted from a supposedly complete
dataset. Recheck affected mappings after assay, catalog, protocol, or terminology
version changes. Preserve provenance so a downstream user can identify which
version produced a record.
