# Why Laboratory Results Need LOINC

Three hospitals are connecting their laboratory results to a shared clinical record. A clinician wants to see a patient's glucose results together even when testing was performed at different hospitals. Each laboratory has its own test catalog, local identifiers, and display names.

The interface analyst's first draft groups results by display name. **GLU** from Hospital A and **GLUC** from Hospital B appear under different headings, even though both laboratories report serum/plasma glucose in mg/dL. Hospital C, a partner hospital in Canada also uses **GLU**, but reports in mmol/L. Matching names would combine A with C and miss B.

You are the pathology resident reviewing the proposed mapping with the laboratory information system (LIS) analyst and chemistry staff. The messages arrive successfully; the unresolved question is what each result actually represents. Review the catalog extracts below before choosing how the receiving system should identify these observations.

You will explain why a shared identifier is needed, look up candidate terms on the Logical Observation Identifiers Names and Codes (LOINC) website, check their definitions against the local catalog, and investigate how an incorrect standardized code can still mislead a receiving system. You do not need to know any code numbers before starting.


## What you will be able to do

- Map a laboratory observation using its full definition.
- Compare specimen, units, method and timing.
- Explain why “choose the most common code from a search” is an incomplete approach.

Start by reading the case records. Make a choice before checking the explanation; you can revise it and test again.
