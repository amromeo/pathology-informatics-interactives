# Reviewing Laboratory Terminology Mappings

The laboratory is preparing a new data feed for a cancer registry and clinical
analytics. An analyst used display names from the local test catalog to suggest
mappings. The catalog includes a breast panel order, individual biomarker
results, report findings, and billing entries. Several rows have similar names
but serve different purposes.

You are the resident reviewing the proposals with the terminology specialist.
First identify what each breast-report object represents and which standard
serves the named use. Then review four mapping decisions, including two
chemistry records supplied by the same catalog-mapping process.

The analyst's draft assigns the same glucose code to both numeric result
fields because both display as GLU. One is reported in mg/dL, the other in
mmol/L. A HER2 entry lacks its assay definition, and BREAST_PANEL is an order
rather than a single observation. Decide which mappings can be supported now
and which require more information.
